# PragyaRoot — Astro starter

A multi-page, responsive Class 10 learning workspace built with Astro and reusable components.

## Pages
- `/` — homepage
- `/class-10/` — subject directory
- `/class-10/science/` — Science hub
- `/class-10/mathematics/` — Mathematics hub
- `/grammar/english/` — English grammar hub
- `/about/` — About PragyaRoot

## Run
1. Install Node.js (LTS).
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open the local address printed in the terminal.

Build for Cloudflare Pages/static hosting with `npm run build`; output is in `dist/`.
